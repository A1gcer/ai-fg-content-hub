# AI 生成内容交付前检查清单

## 1) 事实检查
- [ ] 核心事实是否有来源？
- [ ] 引用是否真实可访问？

## 2) 数据检查
- [ ] 数字是否可复算？
- [ ] 时间、口径是否一致？

## 3) 语气检查
- [ ] 是否符合对象（老板/客户/同事）？
- [ ] 是否存在绝对化表述？

## 4) 场景检查
- [ ] 是否贴合当前业务背景？
- [ ] 是否可直接执行？

## 5) 隐私检查
- [ ] 是否包含敏感信息？
- [ ] 是否泄露内部策略？

## 6) 责任检查
- [ ] 谁是最终审核人？
- [ ] 出错后责任归属是否明确？
