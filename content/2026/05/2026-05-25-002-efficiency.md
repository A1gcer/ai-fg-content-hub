# 为什么你用了AI效率反而没提高？

## 一句话答案
没有建立可复用工作流，效率就会被"反复解释需求"吞掉。

## 适用场景
重复产出固定类型文档（周报、纪要、文案）的人。

## 为什么会这样
1. 每次从头描述任务
2. 追求一次到位，反复重写
3. 不沉淀可复用 Prompt

## 普通人怎么做
1. 每类任务固定一个模板
2. 使用"三轮出稿"（粗稿/细化/终稿）
3. 建立个人 Prompt 库
4. 明确复核点（事实/语气/风险）

## 防翻车检查清单
- [ ] 这次任务是否复用模板？
- [ ] 是否限定了字数、风格和受众？
- [ ] 是否规定了输出结构？
- [ ] 是否有人工复核步骤？
- [ ] 是否沉淀了本次有效 Prompt？

## 可复制 Prompt
```text
你是我的写作助手。请按"粗稿-细化-终稿"三轮协作。
每轮都输出：
- 可直接使用内容
- 需要我补充信息
- 风险点提醒
```

## 可复制 Skill

**Skill：** 三轮协作写作助手
**场景：** 需要 AI 配合一起写文档/报告，从粗稿到终稿
**风险等级：** 🟡 中

**指令：**
```text
你是我的写作助手。请按"粗稿-细化-终稿"三轮协作。
每轮都输出：
- 可直接使用内容
- 需要我补充信息
- 风险点提醒
```

**约束：**
- 每轮必须输出可直接使用的部分
- 标注需要我补充的信息
- 不能直接出终稿

**输出检查：**
- [ ] 粗稿结构完整？
- [ ] 细化阶段补充了场景信息？
- [ ] 终稿前人工核验了事实？
- [ ] 风险提醒都处理了？

## 结论
真正提速靠流程，不靠一次神 Prompt。
