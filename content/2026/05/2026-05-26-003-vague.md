# AI写的东西为什么总是很空？

## 一句话答案
你给的要求太笼统，AI 只能回你"万能模板"。

## 适用场景
"写个方案""写个总结"这类泛任务。

## 为什么会这样
1. 没有明确受众
2. 没有给场景和目标
3. 没有结构和字数约束
4. 没有提供样例

## 普通人怎么做
1. 说明受众是谁
2. 说明使用场景
3. 限定输出结构、长度、语气
4. 提供样例风格
5. 明确哪些不能写

## 防翻车检查清单
- [ ] 受众是否明确？
- [ ] 场景是否明确？
- [ ] 结构是否明确？
- [ ] 是否给了样例？
- [ ] 是否设置禁写边界？

## 可复制 Prompt
```text
请为【受众】在【场景】下写一份【格式】。
要求：
- 字数：xxx
- 结构：1/2/3
- 风格：xxx
- 禁止：空话、套话、未经证实数据
```

## 结论
输入越具体，输出越可用。
