# 哪些事情不能直接交给AI？

## 背景

很多人把 AI 当成"一键完成工具"，但真实工作交付里，这种用法风险很高。

本文来自「AI不翻车FAQ / AI-FG」项目，目标是把 AI 生成内容变成可交付成果。

## 一句话结论

凡是你要承担责任、涉及专业判断或敏感信息的工作，不能直接交给AI拍板。

## 问题本质

1. 责任主体是人不是模型
2. AI不具备执业资格
3. 敏感数据存在泄露风险
4. 高情境沟通需要人际判断

## 更稳的做法

1. 先划定"可交给AI的子任务"
2. 专业结论必须人工复核
3. 涉敏信息做脱敏处理
4. 对外内容走审批流程

## 检查清单

- [ ] 是否需要签字担责？
- [ ] 是否涉及法律/医疗/财务结论？
- [ ] 是否包含敏感数据？
- [ ] 是否需要人际判断？
- [ ] 是否有最终审核人？

## 可复制 Prompt

```text
请仅做信息整理，不给最终结论。
输出时标注：
- 高风险项
- 需要专业人士确认项
- 不可外发项
```

## 结论

AI可以加速过程，不能替你承担后果。
